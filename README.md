# Type & Calligraphy Practice Sheets

Printable practice sheets for type design and calligraphy: ruled guidelines —
ascender, cap height, x-height, baseline, descender, and optional slant lines —
laid out in rows across the page, as a PDF.

A companion to [Type Cooker](https://typecooker.com): Type Cooker gives the
brief, this gives the ruled paper.

## Running it

```sh
npm install
npm run dev        # the app, at http://localhost:5173
npm test           # the tests
npm run typecheck
```

`npm run proof` writes sample sheets to `proofs/`. `npm run fields` lists every
config field with its type, unit and default.
